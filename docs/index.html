Portfolio

Multiple areas of computer science, one development process.

Although each artifact focuses on a different area of computer science, they share the same overall development approach. Throughout the enhancements, I focused on writing intentional code that is logically consistent, maintainable, and designed around practical problems identified in the original applications.

Rather than replacing working solutions simply to make them more complex, each enhancement builds on the strengths of the original artifact while addressing limitations in its design, functionality, reliability, or organization. This required considering not only whether a solution worked, but why it was appropriate and how its components should work together.

Documentation was also an important part of that process. Clear project structure, comments, README files, enhancement narratives, and code reviews help explain both how the applications work and the reasoning behind their design. Together, the three artifacts demonstrate my growth toward developing software that is not only functional, but purposeful, understandable, and easier for others to maintain and build upon.

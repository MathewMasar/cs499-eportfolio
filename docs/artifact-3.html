Grazioso Salvare Animal Shelter Dashboard

A standalone Dash and MongoDB application featuring advanced searching, geospatial data, rescue filtering, administrative reporting, secure configuration, and automated testing.

Artifact Overview

This artifact originated in CS 340: Advanced Programming Concepts. The original project combined MongoDB with a Jupyter Notebook dashboard to search and visualize animal shelter records for the fictional Grazioso Salvare organization.

For the capstone enhancement, I rebuilt the project as a standalone modular Dash application. The enhanced system includes advanced searching, MongoDB indexing, geospatial functionality, rescue filtering, administrative reporting, secure environment-based configuration, stronger validation, and automated testing.

Software Engineering and Design

LED/LCD State Simulator

A Raspberry Pi client-server application redesigned into a modular embedded system with separate hardware, serial communication, state management, and configuration components.

Artifact Overview

This artifact originated in CS 350: Emerging Systems Architectures and Technologies. The original project used Raspberry Pi hardware, an LCD display, LEDs, buttons, and serial communication to demonstrate a client-server state machine.

For the capstone enhancement, I focused on software engineering and design. The application was reorganized into separate components responsible for hardware control, serial communication, state management, and configuration. The enhanced version also includes stronger validation, error handling, logging, and safer management of concurrent LCD updates.

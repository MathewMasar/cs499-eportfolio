Algorithms and Data Structures

Appointment Service Scheduler

A multi-service scheduling system using complementary data structures to support direct lookup, chronological organization, appointment availability, and efficient next-appointment retrieval.

Artifact Overview

This artifact originated in CS 320: Software Testing, Automation, and Quality Assurance. The original application provided basic appointment creation, storage, updating, and deletion.

For the capstone enhancement, I expanded the application into a multi-service scheduling system. HashMap, EnumMap, TreeMap, and PriorityQueue structures support different scheduling and lookup operations, while additional validation, scheduling rules, automated tests, and a runnable demonstration provide a more complete implementation.
